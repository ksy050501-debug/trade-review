# 무역 탐정단

「무역의 발견」 공개수업 **전날 40분**에 하는 모둠 복습 활동 웹앱입니다.
지난 차시에 배운 **무역·수출·수입의 뜻**을 모둠 게임으로 복습하고, 마지막에 **"나라들은 왜 서로 무역을 할까?"**라는 궁금증을 남겨 다음 날 수업으로 이어 줍니다.
모둠 이름은 내일 학생들이 맡을 나라(가온국·나래국·다온국·라온국)와 같습니다. 모둠마다 태블릿 한 대를 씁니다.

| 주소 | 누가 | 하는 일 |
|---|---|---|
| `/` | 모둠 태블릿 | 입장 코드 → 모둠 고르기 → 사건 풀기 |
| `/teacher` | 교사 PC | 구글 로그인, 수업 방 만들기, 단계 진행, 점수·진행 현황, 발표 화면, 정답 보기 |
| `/demo` | 누구나 | 인터넷 연동 없이 한 기기에서 미리 해 보기 |

## 40분 진행

| 단계 | 시간 | 모둠 활동 | 점수 |
|---|---|---|---|
| 1. 탐정단 입장 | 3분 | 입장 코드 입력, 모둠 고르기, 탐정단 약속 읽기 | |
| 2. 사건 1 · 진짜일까, 가짜일까? | 7분 | 문장 8개를 진짜/가짜로 판정 (서비스도 무역인지, 돈은 어느 쪽으로 가는지, 상대 나라 입장, 나라 안 거래 등) | 40 |
| 3. 사건 2 · 수출일까, 수입일까? | 9분 | 상황 카드 10장을 우리나라 입장에서 분류 (수출 5, 수입 5) | 50 |
| 4. 사건 3 · 물건의 여행 지도 | 10분 | 물건 7개(바나나·연어·포도·철광석·원유·자동차·반도체)의 배송 이야기를 읽고, 지리 단서로 나라를 찾아 수출·수입 방향 고르기 | 70 |
| 5. 마지막 사건 · 이상한 사실 | 7분 | 수수께끼 카드(바나나·자동차·석유) 중 하나를 골라 "왜 그럴까?" 추측과 질문 적기 | 없음 |
| 6. 수사 보고 · 질문 모으기 | 4분 | 발표 화면에 네 모둠의 질문 + "나라들은 왜 서로 무역을 할까요?" + 최종 점수 | |

- **점수는 처음 제출한 답**으로 매깁니다. 틀린 곳은 빨간 표시가 나오고, 고쳐서 다시 내야 사건이 해결됩니다(점수는 그대로). 그래서 모둠이 제출 전에 충분히 의논하게 됩니다.
- 마지막 사건에는 점수가 없고 **정답도 알려 주지 않습니다**. 답은 다음 날 「무역의 발견」에서 학생들이 직접 찾습니다.
- 오른쪽 아래 **갈매기 선장**을 누르면 지금 할 일을 알려 줍니다.
- 교사 화면 맨 아래 **정답 보기**에 모든 정답이 있습니다.
- 사건 1·2의 카드 순서는 모둠마다 다르게 섞입니다(새로고침해도 같은 순서). 줄이나 순서로 정답이 드러나지 않게 했습니다.
- 사건 3은 실제로 두 나라가 같은 물건을 서로 사고팔기도 해서, 물건마다 '한 번의 배송 이야기'로 방향을 정했습니다. 나라는 지리 단서로, 방향은 이야기로 찾습니다.
- 지도는 수업용으로 단순하게 그린 것이라 국경이 정확하지 않습니다.

### 카드에 쓴 사실
바나나(필리핀), 연어(노르웨이), 포도(칠레), 철광석(호주)을 들여오고, 자동차(미국)와 반도체(중국)를 많이 파는 것은 오랫동안 이어져 온 우리나라 무역 관계입니다. 원유는 2026년 중동 정세로 들여오는 나라 순위가 달라지고 있어 "중동 나라에서 들여온다"고만 적었습니다.

## 설치 (한 번만, 약 5분)

본 수업과 **같은 Firebase 프로젝트**(trade-discovery-2ac23)를 씁니다. `js/firebase-config.js`에 이미 값이 들어 있고, 기록은 `reviewRooms`라는 따로 된 칸에 저장되어 본 수업 방과 섞이지 않습니다.

1. **보안 규칙 다시 게시**: Firebase 콘솔 → Firestore Database → 규칙 탭 → 이 저장소의 `firestore.rules` 내용을 통째로 붙여 넣고 **게시**. (본 수업 규칙도 함께 들어 있어 본 수업은 그대로 동작합니다.)
2. **Vercel 배포**: vercel.com → Add New → Project → 이 저장소 Import → Framework Preset **Other** → Deploy.
3. **로그인 허용 도메인 추가**: Firebase 콘솔 → Authentication → 설정 → 승인된 도메인 → 새 배포 주소 추가.

## 수업 당일

1. 교사 PC에서 `배포주소/teacher` → 로그인 → **새 수업 방 만들기**
2. 위쪽 **발표 화면** 탭을 프로젝터에 띄우면 1단계에서 입장 코드가 크게 보입니다.
3. 모둠 태블릿에서 `배포주소`를 열고 코드 입력 → 모둠 고르기
4. 교사 화면 점수표에서 모든 모둠이 '해결'이 되면 **다음 단계 ▶**

새로고침하거나 화면이 꺼져도 그대로 이어지고, 제출 전에 고른 답도 남아 있습니다. 잘못 고른 모둠은 접속 현황의 **[자리 비우기]**로 다시 고르게 할 수 있습니다. 인터넷이 안 되면 `/demo`를 교사 PC에서 띄워 모둠 대표가 나와 조작합니다.
